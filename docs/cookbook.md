# lgctools Cookbook
From discussion: Siva, Victor

## Installation (Siva will verify prerequisites for install)
Clone the repository.
`$ git clone https://github.com/sivasubramanics/lgctools`
`$ cd lgctools`
`$ python3 setup.py build`

Invoke lgctools:
`$ lgctools`

Display lgctools options:
`$ lgctools --help`
